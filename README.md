# database_design_progect_GameInformer

## Overview
Hi folks, welcome to my project on relational database design, where I've decided to build a database for the video game media outlet GameInformer.

I made this project as part of my coursework at the University of Colorado Boulder, and it covers the steps from creating an Entity Relationship Model to normalizing the Relational Model to 3NF. I chose GameInformer for this project due to my interest in video games in general and GameInformer's unique position in the video game media market. It was established in 1991, survived a shutdown in 2024, and continues to print physical magazines in 2026!

The database supports publishing articles on the website, communication between users, publication of physical magazines, and subscriptions to them.
